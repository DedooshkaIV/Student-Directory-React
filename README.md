# Student Directory

A responsive Student Directory web application built using React and Bootstrap.

## Features

- Responsive navigation bar
- Student profile cards
- Profile view counter using useState
- Show/Hide student details
- Delete confirmation alert
- Add New Student informational alert
- Bootstrap pagination
- Responsive grid layout
- Footer with quick links and contact information

## Technologies Used

- React
- JavaScript
- Bootstrap 5
- HTML and CSS
- Vite

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev
